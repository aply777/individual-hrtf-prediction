# Legacy FFM23 demonstration volume

This directory is a preserved visual sample from the earlier three-database
`FFM23` frozen-TEST export. It contains 43 CARLab test ears and is retained for
provenance and for inspecting the historical HEALPix plotting convention.

It is **not FFM26 evidence** and must not be used to state FFM26 validation or
final-test performance. Do not overwrite files in this directory with a later
run; publish later full-map exports as separately named release assets.

The original scalar metrics and all-ear table remain in `_LOCKED_metrics.txt`
and `_ALL_subject_errors.csv`.
